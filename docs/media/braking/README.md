# Complete native stopping recordings

Each GIF renders one entire 15-second native probe, from its initial state
through standing, commanded movement, braking and the final hold. Playback is
real time at 10 fps with an additional one-second terminal outcome card.
There are no temporal cuts. The adjacent JSON records qualification results,
frame coverage, commands and policy/source/artifact hashes.

These are loaded-start magnetic-fixture locomotion probes, not complete pickup
and delivery missions. Only complete movement-and-stopping passes are embedded
in the main README; all failed evaluation cases remain in the experiment reports.
